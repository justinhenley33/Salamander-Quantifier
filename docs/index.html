How to Use Salamander Quantifier

1. Upload an image

Click Upload in the top bar and choose a salamander image from your computer.

2. Segment a region

Click points around the salamander region you want to analyze. Double click to close the polygon. Try to select only the region of interest and avoid background areas.

3. Run color analysis

After the polygon is closed, click Color Analysis. The site will analyze only the pixels inside the selected region.

4. Export results

Use the Export menu to download either the detailed color CSV or the binned color CSV. The detailed CSV contains more precise pixel level color data, while the binned CSV groups similar colors together.
